# Paradigma Funcional (Haskell)

En este apartado se encuentran los archivos correspondientes al primer paradigma de la cursada. Utilizamos **GHCup** y el intérprete **GHCi** para ejecutar las soluciones.

### 🛠️ Herramientas Utilizadas

- **Lenguaje:** Haskell
- **IDE:** VS Code (Extensions: Haskell Syntax Highlighting)
- **Entorno:** GHCi en terminal MINGW64

### 📖 Contenido de los Archivos

Los archivos están numerados por orden de aprendizaje:

1. **[01_introduccion_funcional.hs](./01_introduccion_funcional.hs)** : Conceptos básicos, guardas y transparencia referencial.
2. **[02_aplicacion_parcial_y_composicion.hs](./02_aplicacion_parcial_y_composicion.hs)** : Currificación y el uso del operador `(.)` para componer funciones.
3. **[03_practica_tipos_y_modelado.hs](./03_practica_tipos_y_modelado.hs)** : Tipos de datos algebraicos (`data`), pattern matching y alias de tipo.
4. **[04_listas_y_orden_superior.hs](./04_listas_y_orden_superior.hs)** : Manejo de listas, funciones de orden superior (`filter`, `any`, `all`) y listas por comprensión.
   - **[04_practica_orden_superior.hs](./04_practica_orden_superior.hs)** : Ejercicios de práctica de orden superior.
5. **[05_recursividad.hs](./05_recursividad.hs)** : Recursividad pura sobre listas y funcionamiento de fold.
   - **[05_practica_recursividad_orden_superior.hs](./05_practica_recursividad_orden_superior.hs)** : Ejercicios de recursividad con implementaciones de fold.
6. **[06_lazy_evaluation.hs](./06_lazy_evaluation.hs)** : Cómo funciona la Lazy Evaluation en Haskell.
   - **[06_practica_lazy_evaluation.hs](./06_practica_lazy_evaluation.hs)** : Ejercicios de lazy evaluation, fold y orden superior.
